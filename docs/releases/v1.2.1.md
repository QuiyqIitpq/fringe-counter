# v1.2.1 — Editable regions and bilingual interface

Historical milestone: editable multi-region counting, separate include/show controls, undoable exclusion/cleaning/stitching, revision history and Chinese/English offline reports.

Download `fringe-counter-v1.2.1.zip`, extract it and follow README. This is a source package requiring Python and FFmpeg, not a standalone binary. Mac users can run `首次安装.command` and then `启动条纹计数.command`.

Checks: 28 Python tests, 6 DOM tests and 2 chart/primary-output checks passed on macOS. The package does not include private recordings, laboratory reports, Python environments or personal default paths. Numerical implementation is retained from the local version.

Counts can remain conditional or model-based. Unresolved branches, sampling assumptions and trend-stitching estimates must be reviewed; no calibrated experimental-accuracy guarantee is made. Source and limitations are documented in the package. No license has been selected.

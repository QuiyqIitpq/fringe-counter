# v1.7.0 — Balanced tracking and optional full spatial review

Current recommended version. Adds balanced all-frame tracking with a single video decode, cached computation and up to five ROI workers. Full mode adds dense multiscale spatial review. Retains adaptive same-pair filtering, local reference checks and separately preserved raw/model outputs.

Download `fringe-counter-v1.7.0.zip`, extract it and follow README. This is a source package requiring Python and FFmpeg, not a standalone binary. Mac users can run `首次安装.command` and then `启动条纹计数.command`.

Checks: 65 Python tests, 9 DOM tests and 5 chart/primary-output checks passed on macOS. The package does not include private recordings, laboratory reports, Python environments or personal default paths. Numerical implementation is retained from the local version.

Counts can remain conditional or model-based. Unresolved branches, sampling assumptions and trend-stitching estimates must be reviewed; no calibrated experimental-accuracy guarantee is made. Source and limitations are documented in the package. No license has been selected.

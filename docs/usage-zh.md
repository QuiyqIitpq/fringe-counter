# v1.2.1 使用说明

## 安装与启动

先安装 Python 3.10+ 与 FFmpeg（需同时有 ffprobe）。Mac 双击“首次安装.command”建立当前目录的 `.venv` 并安装 NumPy / Pillow；再双击“启动条纹计数.command”。保留终端窗口直到用完程序。

若提示缺少依赖，重新运行首次安装入口，并保留完整报错信息。启动器优先使用当前目录的 `.venv`，不借用其他版本目录。公开包不包含录像，启动后请选择自己的视频。

## 计数框

自动候选框上限可调整，候选不足时不会用暗区凑数。手动模式可连续添加多个框，选中后可拖动中心或右下角移动/缩放，也可输入坐标和尺寸。虚线框是搜索范围，实线框才参与计数。框宽高至少 64 原始像素，长宽比不超过 8。

几何修改后点“分析 / 复算修改的框”。未变框可复用兼容的轨迹；修改几何仍需解码原视频。预览时刻只影响候选检测，不裁掉先前视频，也不表示加热起点。

## 统计、处理与语言

“参与统计”会改变主结果；“显示曲线”只改变图像。参考位置固定，改变它会产生新处理版本。可选时间区间、翻转符号并检查相邻原始灰度帧。

排除建议、保守清洗、趋势拼接与撤销继续可用。拼接需要先预览，假设邻近慢趋势穿过扰动区间，不能称为恢复丢失条纹。请保留原始对照。

右上角 English / 中文 切换界面与结果解释。当前工作保留，文件路径和原始 JSON/CSV 不翻译。浏览器允许时会记住同一访问地址下的语言；端口改变可能需要重新选择。


## 保存与旧任务

结果写入当前安装的 `results/`，每次统计保留独立修订。`raw.json` / `raw_tracks.npz` 是原始层；修订中包含配置、CSV、解释和 HTML。新报告可离线切换语言，编辑和重算需回到程序。

公开版只自动列出当前 `results/`。迁移自己的旧任务时，先备份，再把整个任务目录复制到这里，保留所有原始文件及修订；原视频仍需位于记录的路径。不同版本对同一录像的比较需保持框、参考位置与处理配置一致。

计数的条件性、时间采样、整数混叠与物理标定边界见 [限制](limitations.md)。

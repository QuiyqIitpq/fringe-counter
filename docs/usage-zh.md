# 离线干涉条纹计数 v1.1

用于已经录好的 AVI、MP4、MOV 等视频。在这台 Mac 上处理，支持正向、反向和小数条纹计数。原视频不会被修改。

## 第一次使用

1. 双击同目录的 **启动条纹计数.command**，保持弹出的终端窗口打开；浏览器会自动打开程序。
2. 此公开版本不包含原实验录像和预先计算的铝样品范例。请选择自己的视频，或按下面的测试步骤生成合成视频。
3. 处理其他视频时，粘贴文件路径后点 **读取视频**，或点 **选择文件…**。选择文件会复制一份到程序目录的 `results/uploads/`；填写路径则直接读取原文件。
4. 默认自动找 7 个清晰区域。也可以先选择一个条纹清楚的预览时刻，在画面上拖出搜索框，再点 **开始分析**。搜索框要足够大，能放入多个约 192×192 原始像素的小区域；只圈一两条纹通常太小。分辨率很高时最小区域会相应变大。
5. 分析完成后调整开始、结束时间，查看正向累计、反向累计与净变化。

程序读取所有帧，不通过跳帧加速。预览时刻只影响选区，不是加热开始时间，也不会裁掉前面的数据。框选只限制分析位置，不会把画面其他部分一起平均。

## 怎样检验计数

- 一个完整亮→暗→亮周期算 **1 条**。从亮到暗只算半条。
- 例如先前进 10.35 条，再后退 2.20 条，净变化应为 **+8.15 条**。
- **原始方向**是程序定义的图像相位方向；可以翻转正负。尚未校准为样品向上/向下或膨胀/收缩。
- 先在“可单独检查的连续区间”选一段较短、清楚的片段。曲线允许来回波动，程序逐帧把正负变化相加。
- 点击曲线定位帧，或在“相邻帧核对”输入右图帧号，然后点 **读取这两帧**。左右两图是同一区域的相邻原始灰度帧；可换 ROI、前进/后退一帧。这里需要原始视频仍位于记录的路径。
- 彩色曲线是不同区域的相位轨迹。真实倾斜、条纹形变与识别误差都可能造成不同区域结果不同；程序将多个区域的变化融合到一个固定画面点。

不要将“正向累计”和“反向累计的绝对值”相加当成热膨胀条数。它们也会累计来回振动；所需代数量是 **正向累计 + 带负号的反向累计**。

## 红色标记与准确度

界面区分两种结果：

- **连续追踪净变化**：所选区间每一步通过当前信号和区域一致性检查。
- **条件估计净变化**：区间包含信号缺失、区域不一致或可能漏计整数条纹的步长，显示值只供检查，不能当作已确认真实总量。

即使检查全部通过，也仍假定相邻帧真实运动小于半条。超过这一采样限制时，周期图案可能看起来移动得较少或方向相反，单靠这份录像不一定能恢复漏掉的整条。红色标记不能覆盖所有可能的时间混叠。

**0.1 条可以作为清晰连续视频的验证目标，但本程序没有为这段实验视频证明 ±0.1 条准确度。** 界面显示到 0.01 条仅为了观察小数变化。合成数据误差、区域间差异和真实测量不确定度是不同的量。

## 自动漂移候选起点

程序比较约 10 秒窗口内的持续趋势与往返波动，并要求趋势延续，给出一个候选起点。找不到时可手动选段。

候选起点不是温度测量，不能证明此时刚开始加热；激光、桌面、空气和热台漂移也可能有方向性。请结合你对操作过程的记忆核对。候选时间需要结合具体视频与操作记录核对。

## 保存与再次打开

每次分析自动在 `results/日期时间_编号/` 保存一组文件：

| 文件 | 用途 |
|---|---|
| `report.html` | 离线交互报告，打开后可选时间区间、翻转符号、导出所选区间 |
| `fringe_counts.csv` | 逐帧时间、带符号增量、条件累计、质量标记和各区域轨迹 |
| `result.json` | 完整结果、分析参数、区域坐标、候选漂移起点和限制 |
| `selected_interval.json` | 点击“导出所选区间”后保存的区段结果和符号选择 |
| `unsafe_intervals.csv` | 需要核对的时间区间与原因位码 |
| `selected_regions.png` / `phase_over_time.png` | 选区图与曲线 |
| `tracks.npz` | 后续复查用的数值数据 |

离线报告的图像与 HTML 应放在同一文件夹。若浏览器未保存区段下载文件，可以复制报告显示的 JSON 文本保存。离线报告可独立看曲线；逐帧查看原视频需回到运行中的程序。结束使用后，在终端按 Ctrl+C 即可停止本机服务。

## 测试与移到其他电脑

随程序提供 9 项核心测试、含正反向与抖动的合成 AVI 全流程，以及 YUV420 压缩视频的奇数坐标框选测试。首次发布的复测结果见 [验证说明](validation.md)。真实实验精度仍需独立验证。

合成 AVI 真值 8.15 条，自动选区结果约 8.14965 条；有损压缩并手选区域的结果约 8.14471 条。**这些是算法测试，不是真实实验的误差标定。** 合成视频生成脚本随程序提供，生成视频与运行结果不包含在 GitHub 仓库中。

运行需要 Python 3.10+、FFmpeg/FFprobe、NumPy 和 Pillow。Mac 可先从官方渠道安装 Python 与 FFmpeg，再在程序文件夹终端运行：

```sh
python3 -m venv .venv
.venv/bin/python3 -m pip install -r requirements.txt
.venv/bin/python3 app.py
```

命令行分析：

```sh
python3 app.py --video '/完整路径/视频.avi' --out 'results/本次实验' --preview 30
```

复现测试（先生成合成视频，再检查手选区域）：

```sh
python3 -m unittest discover -s tests -p 'test_core.py' -v
python3 tests/validate_video.py
python3 tests/check_manual_roi.py
```

本程序采用局部傅里叶侧带相位提取、帧间复相位差与多个区域的鲁棒融合。方法背景可参见 [Takeda, Ina & Kobayashi (1982)](https://doi.org/10.1364/JOSA.72.000156)。本实现并非该论文提供的软件，也未由论文结果验证本次实验准确度。

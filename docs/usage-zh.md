# v1.3.0 使用指南

- 框内相位平面拟合，滤波器更新时重新计算同一对前后帧。
- 默认允许固定参考点直接测量，但要求有效框中心恰好与参考点重合，且明确区分于多框校验。
- 完整通过计数、合格部分和与条件诊断和分开显示。
- 增加连续可读区间、断点原因和原始帧检查。
- 尚不包含后续的联合整数候选与密集空间复核；未解决的间断仍明确保留。

参考点直接测量降低了多框支持等级，不能生成缺失相位或在无有效区域覆盖处外推。未解决区间不能当作完整可靠总数，后续版本还有进一步改进。

## 第一次启动

安装 Python 3.10+ 和 FFmpeg（需同时有 ffprobe），运行根目录的“首次安装.command”建立当前文件夹的 `.venv`，再运行“启动条纹计数.command”。保留终端，使用结束后按 Ctrl+C。安装说明与跨平台命令见 README。

## 操作

读取自己的视频，选择条纹清楚的预览时刻；自动生成候选框，或手动连续添加矩形框。拖中心移动、拖右下角缩放，也可输入坐标与尺寸。虚线框只是搜索范围，实线框才计数。

修改框后需重新分析；“参与统计”影响融合，“显示曲线”只影响图像。改变参考点会生成新配置。原始轨迹与可撤销处理分别保存。拼接需预览，并保留估计假设；它不等于恢复真实丢失条纹。

右上角 English / 中文 切换界面，保留当前框、区间、撤销记录和拼接预览。原始 JSON/CSV 与文件路径不翻译。新导出的报告支持离线切换；要修改或重新计算，请在程序中打开历史任务。

## 保存与比较

任务保存在本安装的 `results/`。迁移旧任务需先备份，再复制完整任务文件夹，包括原始数组和修订；原视频仍需位于记录路径。版本比较必须使用同一视频、计数框、参考点和处理配置。

采样、整数歧义与模型估计限制见 [限制](limitations.md)。选版本可看 [功能与速度对照](version-history.md)。

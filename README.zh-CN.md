# 离线条纹计数 v1.6.0

[中文](README.zh-CN.md) | [English](README.md)

**复核优先的慢速参考版 · 实验研究原型 · 中英文界面**

## 本版特性

- 默认在追踪后追加密集空间复核，检查多个网格尺度、锚点和局部梯度连接。
- 保留 v1.5 的自适应同帧对滤波与固定参考点局部复核。
- 保存空间证据、失败原因及仍有歧义的整数候选，原始结果与模型估计分别保留。
- 主卡片、曲线、正反向累计与 CSV 使用同一主结果模式。
- **速度较慢，是复核优先的参考版本。** 适合更重视细致空间检查、愿意等待或需要复现 v1.6 流程的用户。
- 改变参与框或参考点后，旧空间证据不再使用；显示开关不改变统计。

“复核优先”描述分析取舍，不代表已用独立真值证明本版最精准。v1.7 完整模式保留同类复核，不能笼统认为 v1.6 比它准确。更多复核也不能消除所有整数混叠，模型总数仍需结合未解决区间和敏感性读取。

[查看各版本速度与功能取舍](docs/version-history.md) · [全部下载](https://github.com/QuiyqIitpq/fringe-counter/releases)

## 运行

需要 Python 3.10+、FFmpeg / FFprobe、NumPy 和 Pillow。Mac 安装 Python 和 FFmpeg 后，先运行 **首次安装.command**，再运行 **启动条纹计数.command**，并保留终端窗口。首次安装需要联网；分析视频在本机进行。这是需要依赖的源码包。

选择视频 → 添加或自动生成计数框 → 分析 → 检查区间、方向、质量和相邻帧 → 保存导出。右上角 **English / 中文** 可保留当前工作并切换；新导出的 HTML 支持离线切换，重新计算需回到程序。

公开包不附私人录像或实验结果，历史任务仅列出当前目录的 `results/`。详见 [使用指南](docs/usage-zh.md)、[验证](docs/validation.md)和[限制](docs/limitations.md)。

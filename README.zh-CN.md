## 版本怎么选

- **v1.3.0：** 原始观测与断点诊断优先，尚无后续密集空间复核。
- **v1.6.0：** 复核优先的慢速参考版，默认追加完整密集空间检查，适合仔细复核或复现旧流程。
- **v1.7.0：** 日常使用推荐；均衡模式速度优先，完整模式保留同类密集复核并优化计算。

v1.6 并未经过独立真值验证为“最精准”，也不能笼统说它比 v1.7 完整模式更准确。[查看全部版本对照](docs/version-history.md)。

## 第一次运行

下载包是源码，需要 Python 3.10+、FFmpeg / FFprobe、NumPy 和 Pillow。

Mac 安装好 Python 和 FFmpeg 后，先双击 **首次安装.command**，安装此文件夹专用的 Python 依赖；完成后双击 **启动条纹计数.command**。运行时保持终端窗口打开，保留隐藏的 `.venv` 文件夹。首次安装需要联网，分析视频在本机进行。

也可以按 [英文说明](README.md#first-run) 用终端安装和启动。Windows / Linux 启动方式列在说明中，本次未验证这些系统。

## 使用

选择视频 → 预览 → 自动生成或手动画计数框 → 分析 → 选择区间与方向 → 查看质量提示和相邻原始帧 → 保存导出。

“参与统计”影响融合和总数；“显示曲线”只改变可见性。修改框位置或尺寸后需重新追踪，处理开关与撤销基于已保存的原始轨迹。

右上角 **English / 中文** 可即时切换，保留计数框、区间、设置与未应用的拼接预览。新导出的 HTML 也支持离线切换；其中统计被冻结，重新计算需在运行中的程序打开历史任务。

公开包不附带实验录像、私人默认路径或预计算实验结果。自己的历史任务保存在 `results/`。

“均衡”模式默认使用 5 个候选框，逐帧提取、局部检查与联合诊断，不自动执行额外密集空间复核。“完整空间复核”会增加 v1.6 的多尺度检查，可能明显更慢。框与参考位置不变时可复用逐框追踪。

并行追踪最多使用 5 个工作进程，并在结果目录建立临时磁盘缓存。空间需求随帧数、框数和处理尺寸增长，程序会检查可用空间；正常结束或报错会清理 `.tracking_tmp`，强制退出时可能残留缓存。

## 怎样理解数值

一个完整 2π 周期算一条，正负是图像相位方向。条件和、模型估计、修复与原始观测需要分别看待。显示三位小数不代表 0.001 条准确度，也不能直接作为已标定的材料热膨胀量。
